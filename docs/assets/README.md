# README assets

- `library.png` — library gallery with 12 demo references and four collections.
- `spaces.png` — a brand-direction board with reference images, text and a colour palette.

Both are unaltered 1320 × 900 captures of DesignOS 0.6.0’s packaged Electron renderer, captured on October 15, 2026. Artwork was created specifically for these screenshots and imported through the app's normal import handler. A separate temporary user-data directory kept the demo isolated from the personal library.

The original demo references were created on October 13 and reused for this DesignOS recapture. These screenshots show the packaged app at capture time; later releases may differ. They contain no customer work, private references or copied competitor assets. Live README icon references use `resources/appIcon.png`.

## Installation artwork

- `download-mac.png` — a static download button using the actual `resources/appIcon.png` and Lucide's Download icon. Rendered at twice its displayed size for crisp text on Retina screens.
- `file-archive.svg` and `terminal.svg` — Lucide FileArchive and SquareTerminal icons from the project's installed `lucide-react` dependency, coloured to match DesignOS. License: [Lucide ISC / Feather MIT](../../resources/licenses/Lucide-ISC.txt).
- The browser setup section uses the actual `extension/icons/icon-128.png` declared in the extension manifest.

## DesignOS branding

The app and extension icons shown here are DesignOS's dark glass-folio artwork. Only exported display images are included in this documentation repository.

All artwork is stored locally in this repository. Download links go directly to GitHub release files.
