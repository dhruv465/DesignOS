Browser companion

Save images, pages and links from Chrome, Brave, Edge, Arc and Dia. Captures wait in a local queue if the app is closed.

Get it on the Chrome Web Store
Set it up
  1. Open the Chrome Web Store page and choose Add to Chrome. Brave, Edge, Arc and Dia install from the same page.
  2. In DesignOS, open Settings → Extension and copy the connection code.
  3. Click the DesignOS icon in your browser's toolbar and paste the code to connect.
  4. For X sync, visit Bookmarks while signed in. The first read sets a baseline; new saves sync afterward. Use Import saves for older bookmarks.
