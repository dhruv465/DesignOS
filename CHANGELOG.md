# DesignOS releases

## 0.6.1

**MCP and setup improvements added to 0.6.1:** clearer Claude Code/Codex/client setup with copy confirmation, individual carousel slides, hidden/trash protection, text-search fallback when the local model is unavailable, and resilient image previews. Extension installation uses the Chrome Web Store only. Existing features below remain included.

Likes in Explore respond instantly. Explore posts open in DesignOS's own viewer and can be added straight to a collection from the right-click menu or the viewer. WordPress sites such as saaslandingpage.com load all their posts, and long text stays inside the details panel. The update button shows download, install and restart progress; a site Explore can't follow turns the Add website card into an empty placeholder frame you can stretch; and colour swatches copy their hex code. No library format change; the browser extension is unchanged from 0.6.0.

[Release notes and downloads](https://github.com/dhruv465/DesignOS/releases/tag/v0.6.1-designos).

Already on 0.6.1? Reinstall from the release to receive the refreshed build; same-version updates are not offered automatically.

## Website and distribution — 2026-10-16

- Added interactive DesignOS website on GitHub Pages, with public downloads, privacy, support and browser setup.
- Added branded Terminal installer output; website serves the current script while downloading existing release binaries.
- Desktop release remains 0.6.0; application and extension release assets unchanged.

## 0.6.0

Automatic X/Instagram sync, full offline X Articles, playable MP4s, ordered carousels, bulk imports, redesigned browser companion and DesignOS branding.

Back up before upgrading: Magpie 0.5.3 and earlier cannot open the upgraded ordered-media library.

[Release notes and downloads](https://github.com/dhruv465/DesignOS/releases/tag/v0.6.0-designos). Historical releases remain archived privately.
