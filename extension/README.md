# DesignOS browser companion

Save pages, images, links, screenshots and supported social posts into your local DesignOS library. Works in Chromium browsers including Chrome, Brave, Edge, Arc and Dia.

## Install and connect

1. Install the [DesignOS Mac app](https://github.com/dhruv465/DesignOS/releases/latest).
2. Download and unzip the matching [browser extension archive](https://github.com/dhruv465/DesignOS/releases/latest/download/designos-extension.zip).
3. Open your browser’s Extensions page, enable **Developer mode**, choose **Load unpacked**, and select the folder containing `manifest.json`.
4. In DesignOS, open **Settings → Extension**, copy the connection code, then paste it into the extension popup and choose **Connect**. Keep the code private.

Chrome Web Store review and publication are separate. The store listing remains an unpublished draft; use the matching release archive until it is available.

## Save and import

Right-click an image, page or link, or use the toolbar to save a page, capture a screenshot or save a visible direct video file. Captures wait locally while DesignOS is closed.

With your signed-in browser, new X bookmarks check every two minutes after your first Bookmarks visit; Instagram saves check every five minutes. The first successful read establishes a baseline. Use **Import saves** for older references: choose 25, 50, 100, 200, 500 or all, and **Stop** to end an import.

X Articles can arrive as offline reading pages, X/Instagram videos as playable MP4s, and carousels as one item with ordered slides. Pinterest, LinkedIn and Cosmos use page-based capture and imports. Website changes can interrupt integrations; not every site/account combination has been verified.

Before upgrading to 0.6.0, back up in **Settings → Data** and update app and extension together. Magpie 0.5.3 and earlier cannot reopen an upgraded ordered-media library.
